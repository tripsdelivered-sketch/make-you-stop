# Film Frame V1 — Engine / Canva Visual System

The approved direction is a **modern production-board frame**, not a generic creator-template look.

## Locked visual rule
Use a thin old-film / 35mm film-strip border around each page. Keep the centre clean and functional.

Do **not** place cameras, TVs, reels, director chairs, clapperboards or other production objects inside the worksheet pages. Those references informed the aesthetic only; the reusable product should stay minimal.

## Why this belongs in the engine
The border is a presentation shell. The existing lane logic already provides the useful content:
- Hooks → emotion + unanswered question
- Storyboard → scene + shot + visual direction + progression + payoff
- Video/Reel → first frame + movement + payoff + CTA
- What to Say → spoken opening + key beats + CTA
- Guide/eBook → structured sections / worksheets

The engine should therefore be able to output structured content into this reusable frame without redesigning the presentation each time.

## Principle
**One visual shell. Proven lane intelligence inside it.**
