## Etsy title
Use a clear buyer-friendly title. Lead with what the item is. Avoid keyword stuffing and repetition.

## First image
Show the actual digital product clearly. Prefer a clean single-product preview rather than a collage.

## Image set
1. Hero/cover preview
2. Actual page preview
3. What is included
4. Who it is for
5. How it works
6. Page/detail preview
7. Instant download / file formats
8. Brand/product story
9. Companion product or bundle (where Etsy allows)
10. FAQ / important notes

## Description structure
1. One-line outcome
2. What this is
3. What is included
4. Who it is for
5. How to use it
6. File formats / sizes
7. Digital-download notice
8. AI-use disclosure when applicable
9. Usage licence
10. Important limitations

## Tags
Use up to 13 accurate, non-duplicative buyer phrases.

## Compliance gate
- Seller-created/designed product
- Not bot-generated
- Not an AI-generated functional guide/instruction manual
- Not an AI prompt bundle
- Listing images accurately represent delivered files
- AI use disclosed when applicable
- IP / trademark check complete
- No unsupported claims

## Publish gate
DRAFT → human review → file QA → listing-image QA → publish manually in Etsy.
